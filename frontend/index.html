📋 Supported CSV Schema & Required Data Format
CSV RFC 4180
Required Columns (Automatic synonym recognition enabled):
account_id * amount * transaction_type * timestamp * location_city *
Optional Enrichment Columns:
currency channel transaction_ref location_country latitude longitude device_id ip_address merchant_name merchant_category
Optional Customer Columns (displayed in Customer / Account Directory):
customer_name customer_email customer_category
💡 Note: merchant_name / merchant_category identify the business where the transaction occurred. customer_name / customer_email / customer_category identify the person who made the transaction — these are separate fields.
💡 Upload Instructions: Transaction amounts must be numeric (e.g. 1250.50). Timestamps can be ISO format (e.g. 2026-11-01 14:30:00). The engine automatically handles account mapping and transaction type normalisation.
